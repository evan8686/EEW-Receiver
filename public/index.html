📌 项目目的

大陆的地震预警系统目前尚未接入台湾中央气象署（CWA）的地震预警。作为受台湾地震影响明显的福建/浙江地区，经常有明显震感，却得不到任何预警。

本项目使用 Wolfx 的 WebSocket API 接口，不使用 Google FCM 推送，确保在大陆网络环境下第一时间收到预警。

✨ 核心功能

  • 实时 WebSocket 连接，毫秒级接收预警推送
  • 达到震级阈值时触发全屏警报、声音和震动
  • 支持锁屏/息屏状态下弹出全屏预警
  • 使用系统闹钟音量通道，不受静音/免打扰影响
  • 前台服务保活，支持多种数据源选择
  • 支持自定义震级阈值

🛠️ 技术架构

Kotlin Jetpack Compose OkHttp WebSocket Foreground Service Android Min SDK 24 Gson Gradle KTS

📖 使用说明

  • 修改阈值：打开 APP 进入设置，修改全屏警报的震级阈值（默认为 3）
  • 授予权限：确保已授予所有必要的通知权限，并配置防杀后台相关权限
  • 安装后测试：点击"模拟触发"按钮，测试全屏弹窗警报功能是否正常
  • 数据源：默认内建台湾中央气象署数据源，可自行勾选更多源
